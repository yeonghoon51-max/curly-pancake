    • 어떻게 동작하나요? 페이지 이미지를 Claude 에 보내 말풍선 위치·원문·번역을 받고, 브라우저에서 말풍선의 흰 부분을 찾아 원래 글자를 지운 뒤 번역을 그 모양에 맞춰 넣어요.
    • 내 API 키는 안전한가요? 키는 이 기기의 브라우저에만 저장되고 Anthropic 으로만 전송돼요. 이 사이트에는 서버가 없어요. 남과 같이 쓰는 컴퓨터에서는 쓰고 나서 설정에서 키를 지워 주세요.
    • 비용은요? 페이지마다 Anthropic API 사용료가 들어요. 번역할 때마다 대략적인 금액을 아래에 보여 드려요. 설정에서 더 저렴한 모델을 고를 수도 있어요.
    • 저작권 이 앱은 본인이 가진 만화를 혼자 읽기 위한 도구예요. 번역한 이미지를 허락 없이 인터넷에 올리거나 나누면 저작권 침해가 될 수 있어요.
