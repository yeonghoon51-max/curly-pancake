# 옛글자 · 고서 타자연습

`index.html`을 더블클릭하거나 VS Code의 Live Server로 실행하면 됩니다.
GitHub Pages 등에 `index.html` 하나만 올려도 그대로 작동합니다.

## 현재 포함
- 훈민정음 서문 세로쓰기 타자 화면 (글자 위에 덮어 쓰는 메트로타이핑식 입력)
- 조합 중 글자 제자리 표시, 확정 시 오타 판정 (빨간 글자 + 원래 글자 곁표시)
- 어절 단위 줄바꿈, 띄어쓰기는 줄 끝이어도 원문대로 입력
- 띄어쓰기 자리 가로 획(–) 표시, 쉼표·마침표는 세워서 진하게 표시
- 화면 아래 가로 안내줄(켜고 끄기 가능)
- 영문 입력 감지 경고
- 번역 줄 옆 곁글: 언해본 / 한문 / 번역만 선택, 친 분량만큼 색이 차오름
- 자모 단위 분당타수·정확도·진행률·오타, 효과음, 완료 결과창과 급수
- 모바일 반응형

4. 왕대/문헌/권/기사 검색, 난이도별 코스
