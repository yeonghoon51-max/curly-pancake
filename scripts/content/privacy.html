시행일: 2026년 11월 2일

‘옛글자 · 고서 타자연습’(이하 ‘사이트’)은 이용자의 개인정보를 수집하지 않습니다. 회원 가입과 로그인이 없고, 입력한 내용이 운영자에게 전송되지 않습니다.

1. 브라우저에 저장되는 정보

편의를 위해 다음 정보를 이용자의 브라우저 저장소(localStorage)에만 저장합니다. 운영자는 이 정보를 볼 수 없습니다.

  • 설정: 테마, 글자 크기, 효과음·안내줄 켜기, 마지막으로 연습한 문헌
  • 연습 기록: 날짜, 문헌, 타수, 정확도, 걸린 시간
  • ‘내 글로 연습하기’에 넣은 제목과 문장

사이트의 ‘기록 모두 지우기’ 단추나 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

2. 쿠키와 분석 도구

사이트는 쿠키, 광고, 방문자 분석 도구를 사용하지 않습니다.

3. 외부 서비스

사이트를 화면에 보여 주기 위해 다음 외부 서비스를 이용하며, 이 과정에서 접속 IP 주소 등이 해당 업체에 전달될 수 있습니다.

  • GitHub Pages (웹사이트 호스팅) — GitHub 개인정보 처리방침
  • Google Fonts (글꼴 제공) — Google 개인정보처리방침

4. 방침의 변경

이 방침을 바꿀 때에는 시행일과 바뀐 내용을 이 페이지에 알립니다.

5. 문의

개인정보와 관련한 문의는 GitHub 이슈로 남겨 주세요.
